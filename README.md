Proyecto de paradigmas de programación , con número de proyecto #3 (Jerarquía de empleados del tipo de empresa [Tipo] ).
# IMPORTANTE
el proyecto de JAVA esta creado en NetBeans version 29, con la gestion de proyectos y compilaciones MAVEN.
Actualmente se usa la version de JAVA 22.0.1
Para un trabajo en equipo correcto , la comunicación es clave para evitar conflictos de archivos y se pierdan avances.
